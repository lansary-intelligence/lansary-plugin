# Changelog

## 0.1.0-beta.1 — 2026-10-15

Initial public beta connection package.

- ChatGPT and Claude installation guides.
- Portable and Claude-compatible remote MCP manifests.
- Public marketplace metadata for supported desktop clients.
- Customer OAuth connection to the hosted, read-only research endpoint.
- Security reporting and service-information links.

This version numbers the public connection package, independently of the hosted backend. Directory review and platform availability are separate from this release.

The installation documentation follows the linked platform guidance. End-to-end installation of this repository in a fresh customer account has not yet been verified.

An unauthenticated automated OAuth-metadata request returned HTTP 403 during preparation. This does not establish whether the interactive OAuth flow works; a fresh customer sign-in remains to be verified.
